WRITE PATH - FULL BLOCK DIAGRAM
legend:  [block]   --{sig}-->  dataflow / handshake   (ch) = per channel


=== AW / CONTROL ===

  aw_ch --{valid,ready}--> [aw_request_validitor] --{valid,ready}--> [a_request_buf]
                                                                     {aw_id, len, size, phy_adr, error}
                                                                             |
                                                   {burst_splitter_ready & aw_request_valid}
                                                                             v
                                                                     [ burst_splitter ]
   [w_rob] <--[rob_idx -> {seg_last, n_pkts, error}]---------------------'  |  |  |
         `-----------------{rob_idx, valid}---------------------------------'  |  |
                                                                               |  `--{ch}------> pkt unit
                                   {skip, stage_len, stage_size, stage_en}      `--{rob_idx}----> pkt unit
                                                   |
                                                   v  (to accumulator)


=== W DATA  ->  STAGE  ->  WD_SRAM ===

  w_data_channal --{w_data_valid & ready}--> [ data_buffer ]{wdata, wstrobe, wlast}
                                                   |
                                                   v
                                           [ burst_acummulator ]
                                             ^    |    |
                                      {take} |    |    `--{stage_valid}--> [WD_SRAM_0]
                                   (clear     |    |    `--{stage_valid}--> [WD_SRAM_1]
                                    stage)    |    |                          ^      ^
                                             |    `--{stage_valid}--> pkt unit |      |
                                             |         (gates commit)   addr={selected_ptr}(ch)
                                             `--(take from pkt unit)                  |
                                                                                 [ frptr ]
                                                                                     ^
                                                                        {inc++ selected_ptr} (on commit)


=== PACKET FORMATION  ->  MC REQ FIFO ===

  {rob_idx},{ch} (splitter) --> [ packet_formation_unit ] --pkt_capture(stage reg)--> [ ch_sel_en_mux ]
                                   ^     ^      ^      |                                  |          |
         {stage_valid} (accum) ----'     |      |      `--{wr_en}--> [ch_sel_en_mux]  {valid0,   {wr_en0,
         {ch0_wr_ptr & ready}            |      |                          |           valid1}    wr_en1}
         {ch1_wr_ptr & ready} (frptr) ---'      |                          |             |          |
         {ready0, ready1} (async_fifo) ---------'                          v             v          v
                                                               [sram0_we][sram1_we]  [async_fifo_0] [async_fifo_1]
         back-edges:  take --> burst_acummulator                                          |
                      wr_en -> ch_sel_en_mux -> WD_SRAM we                   {ready0, ready1} back to pkt unit


=== COMMIT  (ch-gated, one strobe) ===

  commit[ch] = stage_valid & {ch_wr_ptr & ready} & ready[ch]
     => wr_en[ch] (WD_SRAM we) , valid[ch] -> async_fifo , inc++ selected_ptr[ch] , take (clear stage)

  packet staging = data staging: pkt_capture is the stage reg (mirrors burst_acummulator's
  stage_valid), but its valid is channel-gated through ch_sel_en_mux -> {valid0, valid1}.
  SRAM port = data (accumulator) + we (pkt unit wr_en) + addr (frptr selected_ptr), per channel.
